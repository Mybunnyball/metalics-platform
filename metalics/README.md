# متالیکس (METALICS) — نسخه ارائه پلتفرم

پلتفرم مدیریت‌شده B2B برای ساخت قطعات و سازه‌های فلزی سفارشی (الهام‌گرفته از Xometry، بومی‌شده برای ایران).
این نسخه **فقط رابط کاربری** است: بک‌اند و پایگاه داده ندارد و همه داده‌ها نمایشی هستند (`src/data`).

طراحی و توسعه: **علی پیوند**

---

## ۱. پیش‌نیازها (فقط یک بار)

| ابزار | نسخه | از کجا |
|---|---|---|
| **Node.js** | ۲۰ یا بالاتر (نسخه LTS) | https://nodejs.org ← دکمه سبز LTS را دانلود و نصب کنید |
| **VS Code** (پیشنهادی) | آخرین نسخه | https://code.visualstudio.com |

بعد از نصب Node.js، برای اطمینان یک ترمینال باز کنید و بزنید:

```bash
node -v
npm -v
```

اگر شماره نسخه نمایش داده شد (مثلاً `v20.x` یا `v22.x`)، آماده‌اید.

## ۲. اجرای پروژه روی کامپیوتر خودتان

۱. فایل zip را در یک پوشه ساده (مثلاً `D:\projects\metalics`) استخراج کنید. مسیر بهتر است فاصله و حروف فارسی نداشته باشد.

۲. پوشه را در VS Code باز کنید: `File ← Open Folder…`

۳. ترمینال VS Code را باز کنید: منوی `Terminal ← New Terminal` (یا کلید ``Ctrl + ` ``)

۴. وابستگی‌ها را نصب کنید (فقط بار اول، چند دقیقه طول می‌کشد):

```bash
npm install
```

۵. سرور محلی را اجرا کنید:

```bash
npm run dev
```

۶. مرورگر خودکار باز می‌شود. اگر باز نشد، این آدرس را بزنید: **http://localhost:5173**

برای متوقف کردن سرور، در ترمینال `Ctrl + C` بزنید. دفعه‌های بعد فقط مرحله ۵ لازم است.
هر تغییری در فایل‌ها بدهید و ذخیره کنید، صفحه مرورگر خودش به‌روز می‌شود.

### اگر `npm install` خطا داد

- **خطای شبکه یا 403 / ETIMEDOUT:** دسترسی به مخزن npm از ایران گاهی محدود است. یا با VPN/DNS شکن دوباره امتحان کنید، یا موقتاً از mirror استفاده کنید:
  ```bash
  npm config set registry https://registry.npmmirror.com
  npm install
  npm config set registry https://registry.npmjs.org   # برگرداندن به حالت عادی
  ```
- **در PowerShell خطای «running scripts is disabled»:** یک بار این را بزنید و دوباره امتحان کنید:
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```
- **پورت ۵۱۷۳ اشغال است:** Vite خودش پورت بعدی (۵۱۷۴) را انتخاب می‌کند؛ آدرس را از ترمینال بخوانید.

### نسخه آماده (بدون نصب)

پوشه `dist` خروجی ساخته‌شده همین پروژه است. اگر npm کار نکرد و فقط می‌خواهید سایت را ببینید و Python دارید:

```bash
cd dist
python -m http.server 8080
```

سپس http://localhost:8080 را باز کنید. (باز کردن مستقیم `index.html` با دابل‌کلیک کار نمی‌کند؛ حتماً سرور لازم است.)

## ۴. نقشه صفحات

با **Ctrl + K** در هر صفحه، پنجره جستجو باز می‌شود و به همه صفحات و سفارش‌ها دسترسی دارید.
در پنل‌ها، از بخش «نمایش به عنوان» در منوی کناری بین نقش‌ها جابه‌جا شوید.

**سایت عمومی**

| آدرس | صفحه |
|---|---|
| `/#/` | صفحه اصلی: قطعه سه‌بعدی، بارگذاری نقشه، مسیر سفارش، بازارگاه کور، مقایسه |
| `/#/quote` | **ویزارد سفارش و قیمت آنی** (۶ گام: فایل، مشخصات، تحلیل DFM و Nesting، QC، تحویل، ثبت) |
| `/#/capabilities` | خدمات ساخت + قواعد DFM + سطوح کنترل کیفیت + پوشش‌ها |
| `/#/materials` | کتابخانه متریال با جستجو، فیلتر و مقایسه کنار هم |
| `/#/how-it-works` | ماشین حالت سفارش، اسکرو، داوری سه‌مرحله‌ای، لجستیک، پرسش‌ها |
| `/#/suppliers` | عضویت سازندگان + شبیه‌ساز فرمول امتیاز |
| `/#/about` | درباره، بنیان‌گذار، گانت‌چارت ۱۲ هفته‌ای MVP، ایجنت‌ها، پشته فناوری |
| `/#/auth` | ورود با موبایل و کد یکبارمصرف |

**پنل خریدار** — `/#/app` داشبورد · `/#/app/orders` سفارش‌ها · `/#/app/orders/MTX-1405-4790` پیگیری با نقشه زنده، FAI، اسناد و اسکرو · `/#/app/rfq/MTX-1405-4855` ماتریس مقایسه پیشنهادها و پرداخت امانی · `/#/app/messages` چت با ماسک خودکار شماره تماس · `/#/app/disputes/DSP-1405-031` پرونده داوری

**پنل سازنده** — `/#/supplier` پیشنهادهای کار و ارائه قیمت · `/#/supplier/production` کانبان خط تولید (کشیدن و رها کردن) · `/#/supplier/payouts` تسویه‌ها · `/#/supplier/profile` ماشین‌آلات و امتیاز

**پنل کارشناس** — `/#/expert` صف بررسی · `/#/expert/review/MTX-1405-4869` میز بررسی نقشه

**پنل مدیریت** — `/#/admin` مرکز کنترل · `/#/admin/approvals` تأیید چهارچشمی · `/#/admin/suppliers` احراز سازندگان · `/#/admin/surveillance` پایش گفتگوها · `/#/admin/rbac` ماتریس دسترسی · `/#/admin/audit` لاگ ممیزی

> نکته: در ویزارد سفارش اگر یک فایل **STL** واقعی بارگذاری کنید، ابعاد، حجم و تعداد مثلث‌ها واقعاً محاسبه و مدل سه‌بعدی‌اش نمایش داده می‌شود. سایر فرمت‌ها در این نسخه به‌صورت نمایشی تحلیل می‌شوند.

## ۵. ساختار پوشه‌ها

```
metalics/
├─ index.html                 ← صفحه پایه HTML (عنوان و توضیحات سایت)
├─ package.json               ← فهرست کتابخانه‌ها و دستورات
├─ vite.config.ts             ← تنظیمات سرور و build
├─ tailwind.config.js         ← رنگ‌ها، فونت‌ها و انیمیشن‌های برند
├─ public/                    ← فایل‌های ثابت (favicon)
└─ src/
   ├─ main.tsx                ← نقطه شروع برنامه
   ├─ App.tsx                 ← تعریف همه مسیرها (Routes)
   ├─ styles/index.css        ← استایل‌های سراسری (شبکه نقشه‌کشی، گرادیان برند…)
   ├─ data/                   ← ★ داده‌های نمایشی — برای تغییر محتوا اینجا را ویرایش کنید
   │  ├─ catalog.ts           ← متریال‌ها، فرآیندها، سطوح QC، پوشش‌ها، صنایع
   │  ├─ mock.ts              ← سفارش‌ها، پیشنهادها، سازندگان، پیام‌ها، لاگ‌ها…
   │  └─ states.ts            ← ماشین حالت سفارش (طبق Master Blueprint)
   ├─ lib/                    ← منطق کسب‌وکار
   │  ├─ pricing.ts           ← موتور قیمت‌گذاری آنی و مهلت شناور مناقصه
   │  ├─ masking.ts           ← موتور ماسک شماره تماس/ایمیل/وب‌سایت
   │  ├─ scoring.ts           ← فرمول امتیاز سازنده
   │  └─ format.ts            ← اعداد فارسی، تومان، تاریخ شمسی
   ├─ components/
   │  ├─ layout/              ← هدر، فوتر، منوی پنل‌ها، جستجوی Ctrl+K، تعریف منوها (nav.ts)
   │  ├─ ui/                  ← دکمه، نشان، مودال، تب، اعلان، نقشه‌های فنی SVG
   │  ├─ three/               ← صحنه سه‌بعدی فلزی و هندسه قطعات
   │  ├─ quote/               ← اجزای ویزارد سفارش (تحلیل فایل، Nesting)
   │  ├─ charts/              ← نمودارها
   │  └─ app/                 ← اجزای مشترک پنل‌ها و نقشه ایران
   └─ pages/
      ├─ public/              ← صفحات سایت عمومی
      └─ app/{buyer,supplier,expert,admin}/  ← صفحات هر پنل
```

### تغییرات رایج

- **عوض کردن متن‌ها و اعداد نمایشی:** `src/data/mock.ts` و `src/data/catalog.ts`
- **افزودن یا حذف آیتم منو:** `src/components/layout/nav.ts`
- **رنگ‌های برند:** `tailwind.config.js` بخش `colors`
- **ضرایب قیمت‌گذاری (کارمزد، مالیات، تخفیف حجمی):** `src/lib/pricing.ts`
- **صفحه جدید:** یک فایل در `src/pages` بسازید و مسیرش را در `src/App.tsx` اضافه کنید.

## ۶. فناوری‌ها

React 18 · TypeScript · Vite · Tailwind CSS · Framer Motion (انیمیشن) · Three.js / React Three Fiber (سه‌بعدی) · Recharts (نمودار) · Lucide (آیکن) · فونت‌های وزیرمتن و استعداد (داخل پروژه، بدون نیاز به اینترنت)

مسیرها به شکل `/#/…` (HashRouter) هستند تا روی **GitHub Pages** بدون هیچ تنظیم سروری کار کنند.
